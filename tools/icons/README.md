# 发布管线图标

用 Snapshot DSL 生成的图标，四个尺寸一套。

## 文件

| 文件 | 说明 |
| --- | --- |
| `release-pipeline-512.dsl` | 主图，其他尺寸的设计基准 |
| `release-pipeline-128.dsl` | 1:4 等比缩放 |
| `release-pipeline-64.dsl` | 1:8 等比缩放，描边/圆角做过小尺寸补偿 |
| `release-pipeline-48.dsl` | 独立设计，保留三柱 + 加粗箭头 |
| `release-pipeline-32.dsl` | 独立设计，详见下方说明 |
| `release-pipeline-24.dsl` | 独立设计，描边 2.5px，取 16 与 32 之间的值 |
| `release-pipeline-16.dsl` | 独立设计，描边反向加粗到 2px 下限 |
| `build-all.ps1` | 一次渲染全部尺寸 |
| `render.ps1` | 渲染单个 DSL |
| `zoom.ps1` | 把 PNG 局部放大并铺棋盘格，便于检查小尺寸的透明边缘 |

## 设计

- **底**：`Container` + `LINEAR` 渐变（`#0B1B4D → #1E3A8A → #5B21B6`，`TOP_LEFT → BOTTOM_RIGHT`），`borderRadius` 116。
- **三个圆角块**：从左下到右上递进的柱子，表示管线阶段。透明度递进（`#38BDF85C` → `#22D3EEB3` → `#67E8F9`）表达「已完成 → 进行中 → 发布中」。
- **45° 箭头**：指向右上，接在最高阶段之上，表示继续向上发布。

## 箭头的构造法

DSL 没有三角形或多边形图元，所以箭头由三条圆角矩形拼成：

1. **箭杆**：一根*竖直*圆角条，绕自身中心顺时针旋转 45°。
2. **横翼**：从尖端向左的水平圆角条。
3. **竖翼**：从尖端的竖直圆角条。

旋转后竖翼变成水平方向、横翼与之正交，两者自然形成箭头轮廓。竖翼顶部比尖端多探出约 `0.25 × 描边宽度`，用来闭合与横翼的接缝，避免出现缺口。

箭杆定位公式（绕自身中心顺时针旋转 45°，上端中心恰好落在尖端 `T`）：

```
left = T.x - 0.3536 * Ls - S / 2
top  = T.y + 0.3536 * Ls - Ls / 2
```

其中 `Ls` 为杆长、`S` 为描边宽度。四个尺寸的 DSL 里都按此公式填写。

## 为什么 16 / 24 / 32 / 48px 要单独设计

小尺寸下等比缩放会把箭杆缩短到几乎缩进箭翼里，箭头糊成一团。这四个尺寸各自单独设计：

**48px** —— 保留全部三个阶段柱（比 32px 多一个阶段，信息更完整），并把阶段 1 的透明度从 `80` 提到 `7D`，避免在更小的画布上退化成噪点。箭头描边取 64（4.5）与 32（3.2）之间的 3.8。

**32px** —— 尺寸最紧，牺牲最多：

- 丢弃阶段 1（最低透明度的那块在这个尺寸下只是噪点）。
- 柱子压扁压矮，给箭头让出空间。
- 描边加粗到 3.2px、箭杆加长，让斜向轮廓仍然能读出来。

**24px** —— 夹在 16 与 32 之间的过渡尺寸，取中间值：两根柱子（同 32px，丢弃阶段 1），描边 2.5px（介于 16 的 2 与 32 的 3.2 之间），箭杆加长使尾端搭在柱 2 顶部，形成连贯的对角线。

**16px** —— 与上面几个尺寸的方向**相反**：描边不再等比缩小，而是反向加粗到 2px。否则 1.6px 的线在这个尺寸会退化成灰糊。同时只留两根柱子，箭杆加长到 7，使尾端接到柱顶右侧，避免箭头悬空。

## 重新生成

```sh
powershell -File build-all.ps1
```

默认服务是 `https://open-snapshot.muedsa.com`。换服务用 `-BaseUrl`，或设 `SNAPSHOT_URL` 环境变量。若服务启用了 API Key，设 `SNAPSHOT_API_KEY` 环境变量——**不要把它写进脚本或 DSL**。

> 脚本注释保持 ASCII：Windows PowerShell 5.1 会按系统 ANSI 码页读取无 BOM 文件，中文注释会导致解析错误。

## 调整配色

四个 DSL 里的颜色是各自独立的字面量，改一处不会同步到其他尺寸。常用色值：

| 用途 | 值 |
| --- | --- |
| 渐变三停 | `#0B1B4D` / `#1E3A8A` / `#5B21B6` |
| 阶段 1（已完成） | `#38BDF85C` |
| 阶段 2（进行中） | `#22D3EEB3` |
| 阶段 3（发布中） | `#67E8F9` |
| 箭头 | `#F0F9FF` |

改色时记得小尺寸的透明度补偿值与主图不同（128/64/48/32/24/16 分别用了 `70`/`80`/`7D`/`E6`/`E6`/`E6` 结尾的 alpha），要一起调。
